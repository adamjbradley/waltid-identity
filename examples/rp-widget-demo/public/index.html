    Quick Integration Guide
    
            
    Onboard as a Relying Party and add EUDI wallet verification to your site
    

            
    
                
    Step 1: Register as a Relying Party
    
                
    Register your organisation with the RP Registrar. This creates your RP identity with a unique id and clientId.
    
                
    
                    # Register your RP via the admin API
    
                    curl -X POST https://verifier2.theaustraliahack.com/admin/rp \
    
                      -H "Content-Type: application/json" \
    
                      -d '{
    
                        "legalName": "Your Company Pty Ltd",
    
                        "country": "AU",
    
                        "contactEmail": "admin@yourcompany.com",
    
                        "domain": "verify.yourcompany.com",
    
                        "intendedUse": "Age verification for online retail",
    
                        "privacyPolicyUrl": "https://yourcompany.com/privacy",
    
                        "dataRetentionPeriod": "30 days",
    
                        "lawfulBasis": "CONSENT",
    
                        "dpaAcknowledged": true
    
                      }'
    
                    
    
                    # Response: { "id": "a1b2c3d4-...", "clientId": "x509_san_dns:verify.yourcompany.com", ... }
                
    
            
    

            
    
                
    Step 2: Generate a Signing Certificate
    
                
    Generate an X.509 certificate for your RP. This certificate is used to sign EUDI wallet authorization requests (JAR) so the wallet displays your domain as the verifier. The private key is stored securely server-side — you never need to handle signing yourself.
    
                
    
                    # Generate a certificate for your RP (use the id from Step 1)
    
                    curl -X POST https://verifier2.theaustraliahack.com/admin/rp/{id}/certificate/generate
                
    
                
    Response — save this JSON for Step 5:
    
                
    
                    {
    
                      "id": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d",
    
                      "clientId": "x509_san_dns:verify.yourcompany.com",
    
                      "domain": "verify.yourcompany.com",
    
                      "certificate": {
    
                        "subject": "CN=verify.yourcompany.com",
    
                        "issuer": "CN=verify.yourcompany.com",
    
                        "notBefore": "2026-02-09T00:00:00Z",
    
                        "notAfter": "2027-02-09T00:00:00Z"
    
                      },
    
                      "x5c": ["MIIBnz..."],
    
                      "status": "ACTIVE"
    
                    }
                
    
                
    The server generates an EC P-256 key pair and self-signed certificate for your domain. All JAR signing is handled automatically — when a verification session is created with your RP ID, the server signs the request using your stored private key and presents your certificate to the wallet.
    
            
    

            
    
                
    Step 3: Link Your RP to a Verify API Organisation
    
                
    Associate your registered RP with your Verify API organisation using the id from Step 1. This ensures verification sessions use your certificate and domain.
    
                
    
                    # Link your RP ID to your organisation
    
                    curl -X PUT https://verify-api.theaustraliahack.com/v1/admin/organizations/{orgId}/rp \
    
                      -H "Authorization: Bearer {admin_jwt_token}" \
    
                      -H "Content-Type: application/json" \
    
                      -d '{ "rpId": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d" }'
                
    
            
    

            
    
                
    Step 4: Include the SDK
    
                
    
                    <!-- Add this to your HTML -->
    
                    <script src="https://verify-api.theaustraliahack.com/widget/v1/sdk.js"></script>
                
    
            
    

            
    
                
    Step 5: Initialise the SDK with your RP configuration
    
                
    Pass the registration response from Step 2 to the SDK. Your backend fetches a client token using your API key, then the SDK is initialised with both the token and your RP identity.
    
                
    
                    // Server-side: get a client token using your API key
    
                    const response = await fetch('/api/token');
    
                    const { clientToken } = await response.json();
    
                    
    
                    // Client-side: initialise with your RP registration config
    
                    WaltVerify.init({
    
                      clientToken: clientToken,
    
                      rp: {
    
                        id: 'a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d',
    
                        clientId: 'x509_san_dns:verify.yourcompany.com',
    
                        domain: 'verify.yourcompany.com'
    
                      }
    
                    });
                
    
            
    

            
    
                
    Step 6: Verify
    
                
    The EUDI wallet will display verify.yourcompany.com as the requesting party. The authorization request is signed server-side with your RP's certificate — no client-side signing required.
    
                
    
                    // Age verification (modal mode)
    
                    WaltVerify.verifyAge({
    
                      minAge: 18,
    
                      onSuccess: (result) => {
    
                        console.log('User is verified!', result);
    
                      },
    
                      onFailure: (error) => {
    
                        console.log('Verification failed', error);
    
                      }
    
                    });
    
                    
    
                    // Or use inline mode
    
                    WaltVerify.verify({
    
                      template: 'kyc_basic',
    
                      ui: 'inline',
    
                      container: '#verification-container'
    
                    });
